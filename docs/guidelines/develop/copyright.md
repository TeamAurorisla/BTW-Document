# 版权规范

### 第三方内容

- 使用模组、资源包、数据包等开源或授权内容时，**必须严格遵守其原始协议**，保留必要的版权声明与署名
- 所有第三方依赖均通过规范方式打包托管，确保整合包本身不产生违规风险
- 若某项内容无法确认协议或存在争议，**默认不引入本体**

### 原创 / 分离模块

- 由「航迹」衍生出的独立模块（如拆分的模组、工具、资源包），其版权与开源协议由**对应开发者自行决定**，并不自动归属于 Team Aurorisla

### 潜在侵权内容处理方式

若因特殊需求必须使用可能涉及侵权的内容（如未经授权的音乐、素材等），严禁将其打包整合包本体中。该类内容仅允许以个人分享的形式单独提供，并明确说明：

- **仅限学习与交流目的**，不作商业用途
- 版权归原始权利人所有，如有侵权请联系移除
- 不代表 Team Aurorisla 的官方立场，仅供玩家自行选择是否下载使用

整合包本体中使用的音乐必须是已获授权或明确免版权的作品；若希望为玩家提供更丰富的音乐体验，可将额外音乐包以外部分享链接方式提供，并在文档中注明“仅为学习分享目的，请于下载后24小时内删除”等免责提示。
