# 彩蛋内容 披露规范

「航迹」鼓励并支持在游戏中合理融入彩蛋内容，以丰富玩家体验。但所有向公众开放的彩蛋（包括但不限于整合包本体、配套文档、源代码等）必须确保内容健康、安全，不得冒犯任何群体，不得违反现行法律法规及社会公序良俗。

凡属于面向公众的彩蛋内容，必须在 `library/stinger` 文档中进行明确披露，确保项目全体开发者对彩蛋的存在及其具体形式充分知情。
披露内容应至少包括：
- 彩蛋内容
- 彩蛋触发方式或出现位置；
- 彩蛋所涉及的原型或引用来源（如适用）；

### 例外情形

对于**文本叙事与剧情演出**层面的戏仿（neta）、解构或致敬性内容，无需在 `library/stinger` 中披露。但该类内容仍须严格遵守法律法规与公序良俗，不得含有任何不当隐喻或敏感指向。

- 需披露：隐藏角色、特殊物品、彩蛋关卡等具有交互性或显著视觉表现的内容。
- 无需披露：NPC 随口说出的台词，如“我对普通人类没兴趣”。
