# 边栏

文档的边栏使用插件 [`VitePress Sidebar`](https://vitepress-sidebar.cdget.com/zhHans/)，实现了全面高效的自动侧边栏配置。插件的核心逻辑是通过扫描 `docs/` 的目录结构，自动生成侧边栏。文件名便是折叠分组，而 markdown 文件则是分组下的条目。具体配置位于 `.vitepress/config.mts` 的 `withSidebar` 参数中。

::: tip 完整配置
如需查阅全部选项，请查阅 [.vitepress/config.mts](https://vitepress.dev/reference/default-theme-sidebar) 或 [插件官方文档](https://vitepress-sidebar.cdget.com/zhHans/)。
:::

## 排序规则

条目（文件）和分组（文件夹）共用同一套排序规则，由 frontmatter 中的 `order` 字段决定：

1. **先比较 `order` 字段**：在 frontmatter 中声明，未声明时默认为 `0`。（分组的 `order` 字段在目录下的 `index.md` 中声明）
2. 若 `order` 相同时，则按文件名排序。

示例：
```md
---
order: 3
---
```

### 条目排序

条目的排序方式较为灵活，按内容性质选择即可：

| 场景  | 推荐做法 |
| --- | --- |
| 玩法设计、流程说明等叙述性文档 | 使用 `order` 字段，按阅读逻辑排列       |
| 列表、资料库等索引类内容   | 文件名加数字前缀（`01-`、`02-`）即可    |

### 分组排序

虽然分组的排序方式与条目相同，但我们强烈推荐文件夹必须使用 `order` 字段控制，写在文件夹下的 `index.md` 中。不要通过给文件夹名加数字前缀等方式排序，或者干脆不排序，这会导致路径变脏、编辑繁琐。

## 标题规则

侧边栏显示的标题按以下优先级取值：

| 优先级 | 来源 | 示例 |
| :---: | ---- | --- |
| 1 | frontmatter 的 `title` 字段   | `title: 自定义标题`    |
| 2 | 文件第一个一级标题（`#`） | `# 边栏` |
| 3 | 文件名（连字符默认转换为空格）  | `quick-start.md` → `quick start`    |

与排序规则类似，分组的标题也在目录下的 `index.md` 中声明。

### 推荐做法

- **优先使用 `# 一级标题`** 或 frontmatter 的 `title`，让标题可控。
- **不要用中文作文件名**（资料库等列表类目录除外），否则生成的 URL 包含转义字符，可读性较差，难以分享。

## 小结

新增或调整文档时，只要遵循三件事：

1. 文件放在合适的目录下 → 自动归入对应分组。
2. 在 frontmatter 写上 `order` → 控制显示顺序。
3. 在文件顶部写好 `# 标题` → 控制显示名称。

剩下的交给插件处理即可。
