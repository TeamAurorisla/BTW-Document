# 法术系统-原版

魔法资料库记录法术系统中的具体内容与数据，包括法术、工具材料、流派属性、状态效果、附魔与相关属性等。

本分组只记录「有哪些内容」以及它们的具体表现；具体机制规则请参见 [法术与战斗系统](../../design/magic/index.md)。

需要注意的是，奥法新生既是整合包的核心模组，其本身也是一个独立的模组。此资料库所记载内容，是作为独立模组而存在的。作为独立模组，核心机制完全自持，但是在材料和配方上差异较大，整合包需要大幅度修改。

## 内容分类
- 法术
- 工具与材料
- 属性
- 流派属性
- 状态效果
- 附魔
