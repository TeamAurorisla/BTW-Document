# 风暴流派

## 制导
> 与风压互斥，仅在法术是召唤，范围时生效。  

法术释放时，一定会命中范围内血量最高的目标。如果血量一致，则先命中带有“金属”标签或装备盔甲的目标；如果仍然一致，则随机选择一个目标。  

## 风压
> 与制导互斥，仅在法术是投射、跟踪时生效。

法术释放时，有 [一定概率] 会击退目标 3 格范围内的生物，不包括生物本身。
一般而言，法术的稀有度越高，法术精进越高，风压触发的概率越大。    


### 参数
- 风压释放概率；默认 15 %


## 迷失
法术释放时，有概率给予目标短暂的**眩晕**效果。在眩晕生效时，目标短暂的无法移动或攻击。当目标受到伤害时，移除迷失效果。    
如果目标是生物且本身没有仇恨目标，则额外新增**迷失**效果，减少生物的索敌范围；如果目标是玩家，则效果是减少玩家视野范围。

### 参数
- 迷失释放概率；默认 10 %
