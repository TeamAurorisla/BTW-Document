# 法术 GUI

法术 GUI 是模组最重要的界面之一，承担了法术图鉴、法术槽选择等诸多功能。

GUI 的左半部分为法术图鉴，右半部分为法术槽选择界面。

## 元素组件

法术是整个法术 GUI 最基础也是最核心的组件，其呈现出长方形卡牌状。鼠标浮现，会出现卡牌的说明（不是原版的Tooltip）并可以通过中键锁定说明，知道离开说明的范围。在法术上，按 R 键可以进入单独的界面查看法术，在此界面，可以查看法术的配方等详细信息。法术组件应当被设计成可以被流畅的拖动的方式，法术图鉴上的法术可以被拖动到法术槽上。特别的，从法术图鉴中被拖动时，图鉴中的法术不会消失，如果没有被正确放置到法术槽上，法术会直接消失。如果是从法术槽中被拖动，如果没有被正确放置到法术槽或法术图鉴上，法术会回到原来的位置。

可以按 Shift + 左键快速选择或取消选择法术。

## 法术图鉴

左半部分，除了法术外，还应该包括筛选机制。

## 法术槽选择

上半部分。下半部分看着办，塞个图案纹理。右侧可以根据标签切换/新建法术槽。
