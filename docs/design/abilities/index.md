# 能力技能

能力技能是独立于法术体系之外的特殊技能，拥有独特的机制、独立的冷却时间与效果。它们通过快捷键激活，作为玩家战术维度的补充。

::: info
能力技能不属于法术系统，详见 [法术系统](../magic/index.md)。本分组独立于 magic 之外。
:::

## 能力技能槽

一般情况下，玩家默认拥有 **1 个** 能力技能槽，可通过构筑、任务等方式获得额外的槽位，从而装备更多能力技能。

## 能力技能的获取

可通过以下途径获得能力技能：

- 法杖强化
- **传奇法术**（详见 [传奇法术](./legendary-spells/index.md)）
- 构筑系统
- 任务与战利品
- 玩家的开局选择

## 能力技能的使用

能力技能的图标会显示在屏幕右下角，按下对应快捷键即可激活。每项能力技能都有独立的冷却时间。
