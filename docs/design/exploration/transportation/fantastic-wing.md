# Fantastic Wings

不同于伊卡洛斯之翼，Fantastic Wings 模组的翅膀并非装备，而是通过药水培育出的部件，会因为死亡消失，但不会消耗耐久。其定位是临时性的一次性移动工具，成本低廉，可在早期解锁。

然而飞行的优势过于明显：若玩家在战斗场景中随意飞行，会严重破坏关卡设计节奏。因此翅膀在战斗中应被限制使用（如强制收起、无法激活），仅在探索场景中生效。

模组原本的叙事设定是「调制特殊药剂，培育专属羽翼」。我们计划替换这一世界观，将其重新包装为以下两种方向之一：

- **魔法技能**：以剧情叙事包装，翅膀是限时生效的魔法技能（保留药剂物品触发机制）。
- **主动能力**：翅膀作为玩家主动触发的能力，在限定时间内临时生效（使用能力技能触发）。
