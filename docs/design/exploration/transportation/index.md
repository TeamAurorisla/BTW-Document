# 交通

「航迹」的世界由被海洋分割的群岛构成，玩家在不同的区域之间频繁往返。交通系统的存在便是对群岛世界的调味与补充，在保留探索感的前提下，为玩家提供合理的移动手段，避免长途跑图消磨耐心。

需要事先说明的是：交通系统并非单一机制，而是由若干**定位不同、相互补充**的移动方式组合而成。按其**核心体验目标**，可归为两大类：

- **快速移动**——以"到达目标位置"为目的，强调效率与可控性；
- **体验与沉浸感**——不以快速到达为目的，而是让移动过程本身成为体验的一部分，细分为两种：
    - **沉浸感**：让玩家拥有处于世界之中的代入感
    - **新奇感**：通过未知与意外为探索注入惊喜

## 快速移动

快速移动针对有明确目的地的移动需求，减少没有设计价值的跑图时间，方便玩家尽快进入真正的游戏内容，而非长时间航行于空旷、缺乏交互的海域。

### 航线系统

航线与航标系统是跨区域移动的主要手段，详见 [航线与航标系统](../route/)。通过舰队和港口之间的快速移动，玩家可以快速前往目标区域。

### Fantastic Wings

[Fantastic Wings](https://www.mcmod.cn/class/22713.html) 是对于航线系统的补充：港口数量有限，可能相较于目标地点仍有一定距离。模组提供的翅膀用于**中短距离的目标导向移动**，通过低廉的成本和较高的速度，实现快速移动的目的。

> 需要注意的是，翅膀的引入旨在优化大世界探索体验，使用需要有所限制，避免破坏探索与战斗的设计节奏。

## 体验与沉浸感

与快速移动不同，体验与沉浸感的交通方式**不以"尽快到达"为目标**，而是是让移动过程本身成为游戏体验的一部分。这类交通方式在设计上，要么促使玩家**慢下来感受世界**（沉浸感），要么通过**未知与意外**激发探索欲（新奇感），实现对功能性交通的补充，润色节奏，避免玩家的移动体验被单纯的传送与跑图填满。

### 船只 · 沉浸感

- **原版船**：有新的资源包和模型，但还是原版船。
- **[Small Ships](https://www.mcmod.cn/class/4683.html)**：作为原版船的升级形态，有着更加优秀的航海体验，可以成为原版船的升级，实现短途航行。

船只的目标是带来世界感，让玩家能切实感受到自己身在一片群岛世界之中。

### Immersive Gateways · 新奇感

[Immersive Gateways](https://www.mcmod.cn/class/25444.html) 提供了具有优秀视觉效果的随机传送门，作为对常规交通方式的趣味性补充。相较于航线系统的可控性，Immersive Gateways 强调**惊喜感与不可预测性**，传送的位置是随机的，可以带来体验上的新鲜感，也可作为剧情叙事的触发器。

需要注意的是，Immersive Gateways 只是调味剂，不能成为玩家移动的主要手段。
