# 法术系统

「航迹 · Beyond The Wake」的战斗系统以原创魔法模组为核心，灵感来自《部落冲突：皇室战争》等游戏。整体围绕**策略性动态战斗**展开：摒弃传统的固定技能栏与冷却循环，更加侧重于实时的策略选择与资源管理。

目前，魔法模组的名称暂时命名为「Arcane Renaissance · 奥法新生」。我们先制作成独立的模组，再在此模组的基础上进行魔改。

## 核心机制

- **法术槽与候选机制**：玩家从已解锁的法术中选择 8 个（不可重复）构成法术槽。战斗中，系统会从中随机抽取 4 个进入候选槽供玩家施放；施放后从未使用的法术中随机补充一项，形成动态的战术选择。
- **双轨魔力系统**：魔力分为**稳态魔力**与**涌态魔力**两类。稳态魔力可以自然恢复，涌态魔力则需要通过攻击或受击来补充。同时引入了**魔力超载**机制，允许玩家在危急时刻超限施法，进一步增加战斗的策略性。
- **积势系统**：用于限制玩家对强力法术的过度依赖。释放高阶法术需要消耗积势，其高低会对法术的威力与效果产生显著影响。玩家需要在战斗中权衡积势的积累与消耗。

## 法术流派

法术按**流派**进行划分，每个流派都有独特的特性与视觉效果。共有 5 个流派：**炽焰、寒冰、风暴、磐石、神圣**。

正常情况下，玩家通关时可解锁 2-3 个流派的全部法术，以及其他流派的大部分法术。

## 法术精进

法术支持**精进**升级。通过精进，玩家可以提升法术的基础伤害、附加效果等属性，从而增强其整体战斗能力。

法术精进包括 5 个等级：**初识 → 熟练 → 掌握 → 共鸣 → 谐律**。

## 法杖

法杖采用模块化设计，玩家可通过搭配不同模块自定义法杖性能，以适应多样化的战术需求。法杖本身也支持进一步强化（如附魔、宝石镶嵌等），共同构成装备与能力的长期成长路径。

## 美术风格和世界观设计理念

在文艺复兴时期，魔法从神秘学演变为一门可被研究、实践与传承的学科。美术风格定位为**复古工业风（Clockpunk · 钟表朋克）**：以裸露的仪器与黄铜管道、木制面板与羊皮纸卷为元素，又保留了大量传统的手工工具，融合炼金术和手工工房的视觉语言。
