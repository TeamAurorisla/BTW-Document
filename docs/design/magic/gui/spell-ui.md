# 法术界面

随身法术界面左侧是图鉴，右侧是法术组编辑区。随身界面与[档案台](../workbench/archive.md)共用玩家保存的法术组，并显示同一个当前组。

## 元素组件

法术以长方形卡牌呈现。悬停显示卡牌说明，中键可锁定说明，移出说明区域后关闭。悬停时按 R 打开法术详情，查看效果、配方等信息。

从图鉴拖出的是卡牌副本，放入有效法术槽后加入编组。拖出的副本未放入有效槽位时取消操作。从法术槽拖出的法术可以移至其他有效槽位或拖回图鉴移出编组，放到其他位置则回原槽。Shift + 左键可快速加入或移出法术。

## 法术图鉴

图鉴可以筛选法术，并按[可见性规则](../mechanics/mechanics.md#可见性)展示尚未解锁的法术。

## 法术组编辑

右侧显示固定的 8 个法术槽，玩家可通过标签查看和编辑已保存的法术组，也可新建法术组。战斗前或脱战后，玩家可直接在随身界面切换当前用于施法的法术组。编组数量和重复校验遵循[法术组规则](../mechanics/mechanics.md#法术组)。
