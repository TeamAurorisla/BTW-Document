# 编纂仪

编纂仪（Codifier）是一个复杂的大型多方块结构，是进行法术研究的准入门槛。它是玩家从早期探索和小规模尝试进入正式法术研究所必须建造的核心多方块结构。编纂仪建成前，玩家通过探索、战斗和其他途径接触少量法术；编纂仪建成后，玩家可以按照配方系统稳定地合成法术。

编纂仪没有 GUI 界面，配方处理直接在多方块中交互，一次处理一份配方。配方装填完成后，机器会检查输入内容，并输出对应的法术卷轴。同一配方可以重复执行并重复产出法术卷轴。

## 基本结构

编纂仪是一个 **7 格宽 × 2 格深 × 3 格高** 的多方块结构，灵感来源于小型机 PDP-7。机器横向展开，主体由两侧翼板和中央反应区域组成。

其形式如下：

```text
+---------------+
| - x x x x x - |
| x - - - - - x |
+---------------+
```

三层结构一致，其中，“-”为空气方块，“x”为多方块结构的组成方块。中央的 1 * 2 区域为核心反应区，其余则是两侧翼板之间。

编纂仪拥有以下槽位：
- **核心槽**：1 个，用于放置配方要求的核心内容，一般为源质化的抽象元素材料；
- **试剂槽**：共 6 个，分为普通试剂槽 4 个和特殊试剂槽 2 个。
- **书页槽**：1 个，用于放置消耗品奥术书页。

### 核心槽

核心槽位于机器正中央的观察窗内，用于放置配方要求的核心材料。核心材料一般是通用材料，取决于法术的稀有度和法术流派。

观察窗带有可开合的玻璃罩。玻璃罩打开时，机器处于待机状态；材料装填完成后，关闭玻璃罩，编纂仪开始检查配方。

### 普通试剂槽

六个试剂槽中，外侧的四个为普通试剂槽，用于放置配方所需的普通材料。四个普通试剂槽彼此无序，材料满足配方要求即可，投入顺序不影响匹配。

### 特殊试剂槽

六个试剂槽中，靠近中央的两个为特殊试剂槽，用于放置配方指定的特殊材料。两个特殊试剂槽彼此无序，但材料必须符合特殊材料要求。

因此，一份法术配方最多可以包含：

```text
1 个核心材料 + 4 个普通材料 + 2 个特殊材料
```

如果配方不需要特殊材料，则两个特殊试剂槽则没有特殊要求，与普通试剂槽通用。

### 奥术书页（暂命名）

核心材料槽下方设有书页输入机构，用于放置消耗品 **奥术书页**。奥术书页是启动一次编纂所需的记录介质，并在配方完成后消耗。

编纂完成后，法术卷轴从同一机构中输出。

## 配方与编纂

编纂仪采用有序槽位和无序槽位结合的匹配规则：核心材料必须放入核心槽；其余材料放入试剂槽位，如有特殊材料要求，则必须放入特殊试剂槽。编纂仪要求配方完全匹配，只有输入材料的种类与配方要求完全一致，配方才能执行。

编纂时间固定为 8 秒，其中法术卷轴应当在动画结束前输出。如果配方不合法则在运行 1 秒后停止。

编纂流程如下：

```text
观察窗打开时
→ 放入核心材料、普通材料、特殊材料和奥术书页
→ 关闭观察窗
→ 检查配方
→ 执行编纂
→ 输出法术卷轴
```

配方不合法时，机器显示错误状态并重新打开观察窗，不消耗已放入的材料。配方合法时，机器执行一次编纂动画，完成后输出法术卷轴。

法术卷轴是编纂仪的标准产物。具体法术的获取条件和配方决定其是否可以通过编纂仪获得；探索、战斗、任务和法术精进构成其他法术获取途径。

## 美术

### 整体美术效果

编纂仪是一个 7 格宽、2 格深、3 格高的大型多方块结构。整体采用横向展开的乌木柜式结构，由中央核心编纂区和左右两侧的翼板组成，视觉主体是中央核心编纂区的观察窗。其主体形式类似于 PDP-7 为代表的早期小型机，其整体由深色雕刻木材、金属框架、紫铜部件组成。齿轮、压力阀、传动杆和管道部分外露在主体表面，整体保持厚重的柜体轮廓。编纂仪的整体轮廓应当完整、厚重、连续。

### 主体结构
编纂仪由以下部分组成：
- 中央核心编纂区；
    - 核心观察窗；
    - 观察窗下方的书页输入与卷轴输出机构；
- 左右两侧翼板；
    - 正面的六个试剂孔；
- 内部和外露的紫铜传动结构。

主体以深色乌木柜体为主，紫铜用于柜体包边、齿轮、管道、固定环和操作机构。局部使用玻璃、石材和陶瓷表现核心容器、隔离部件与承托结构。

### 中央核心编纂区

中央区域是编纂仪最重要的视觉中心。正中央设置一个厚重的核心观察窗，由玻璃、乌木框架和紫铜金属环组成。

观察窗内部是核心材料的反应区域。核心材料应当位于观察窗中央或略微悬浮在承托座上方。观察窗外部设有可开合的玻璃罩：
打开时，核心区域处于待机状态；关闭后，编纂配方过程开始运行；运行时，玻璃附近出现明显粒子效果；编纂完成后，核心区域的粒子消失，观察窗打开。

核心观察窗下方设置书页输入与卷轴输出机构，作为编纂仪正面的第二个重要区域。

机构应当类似于一个横向放置纸张的书架状结构，内嵌于机器内。当存在材料时，书架的模型应当被填充。在书架顶部有一个窄长机械出料槽，用于输出法术卷轴。

### 两侧翼板

中央核心区两侧是对称展开的乌木翼板。翼板是编纂仪的主体体量来源，应当保持厚重、完整，并与中央区域形成连续柜体。翼板需通过试剂孔、铜管接头、刻度盘和局部齿轮表现其功能。  

翼板略微向前展开，使正面的六个试剂孔形成清晰的横向排列：
- 外侧四个试剂孔对应普通试剂；
- 靠近中央的两个试剂孔对应特殊试剂；
- 六个孔位应当拥有一致的紫铜边框和固定结构；
- 两类孔位可以通过距离、刻度或边框细节进行区分。

每个试剂孔都是一个方形或圆角方形的材料承接口，配有紫铜包边等装饰。放入材料后，孔位可以显示材料本体。在配方运行时，材料消失，不需要特殊动画

### 装饰

编纂仪整体是一个完整结构，只包含少量的仪表、管道、齿轮外显。在细节上可以包括金属包边、铆钉等纹理细节。整体不需要过多的装饰，重点是表现其作为大型多方块结构的厚重感和完整性。

### 运行反馈

编纂仪运行时，中央核心区的观察窗应当显示明显的粒子效果，除此之外，管道装饰、送料口等位置也可以有少量游离的粒子。齿轮应当缓慢的转动。

如果配方不合法，齿轮会在短暂的转动后停止，观察窗应当显示红色的错误状态纹理，并重新打开玻璃罩。


### 整体印象

编纂仪最终应当呈现为一台：

> 横向展开的巨型文艺复兴炼金机械，由中央核心观察窗、两侧试剂翼板、六个材料承接口和书页—卷轴处理机构共同组成。它通过机械传动、材料汇聚和核心反应，将奥术书页与各种试剂编纂为法术卷轴。

它应当比所有功能方块都复杂，但其复杂度应当通过简单的动画、粒子效果显示，并保证明确的功能提示。
