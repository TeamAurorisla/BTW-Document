# 档案台

档案台（Archive）是用于查阅法术详情、编辑法术组和精进法术的功能方块。

## 基本结构

打开档案台后，界面采用翻开的书本或档案袋的布局。

- **图鉴页**显示法术列表，选择法术后在右侧展示详情。详情提供精进入口。
- **法术组页**编辑玩家的法术组，沿用[法术界面](../gui/spell-ui.md#法术组编辑)的交互规则。
- **法术精进**：在主界面的法术详细信息界面中，有按钮可以进入法术精进界面，进行法术升级。

### 精进界面

从法术详情进入精进界面。初次解锁的法术从初识开始，档案台每次提升一级。材料、进阶条件与效果规则见[法术精进](../mechanics/mastery.md)。

界面显示当前精进等级、下一等级的效果变化、所需材料及玩家持有量。该等级有 `Condition` 时，显示条件描述、完成状态及其对本次精进的影响。强制条件未完成或材料不足时，确认按钮显示原因。达到最高等级时，界面显示当前效果。

玩家确认精进后，消耗所需材料，立即更新等级、法术描述和下一阶段的预览。
