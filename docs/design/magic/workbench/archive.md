# 档案台

档案台（Archive）是全量级的法术查看界面。相较于法术 GUI，不仅包括法术图鉴、法术槽选择的功能，还可以升级法术。

## 基本结构

档案台的整体形势类似于翻开的书本/档案袋，由以下 GUI 组件组成：

- **主界面**：左侧为法术图鉴，点击法术，可以在右侧查看法术的详细信息。
- **法术槽选择**：与法术 GUI 内容一致，用于选择法术。主界面是左上角有两个Tab，第二个Tab是法术槽选择界面。
- **法术精进**：在主界面的法术详细信息界面中，有按钮可以进入法术精进界面，进行法术升级。

### 法术精进

法术精进用于提升已解锁法术的效果，并逐步解锁更完整的法术机制。法术精进共有五个等级：

```text
初识 → 熟练 → 掌握 → 共鸣 → 谐律
```

玩家解锁法术时，法术处于**初识**等级。每次精进只能提升一级，升级必定成功，并消耗该阶段要求的材料。法术精进不消耗玩家经验，也不要求玩家反复使用法术来积累统一的经验条。

每个精进阶段可以单独配置一个 `Condition`。Condition 是该阶段的附加条件，可以为空，也可以是可选条件或强制条件：

- **无条件**：满足材料要求后即可精进，适用于大多数普通法术；
- **可选条件**：满足后获得额外效果或降低材料消耗，不影响基础精进；
- **强制条件**：必须满足后才能精进，适用于高强度法术或具有特殊剧情、战斗意义的效果。

Condition 是一次性门槛，不是可重复刷取的经验系统。条件完成后永久记录，玩家不需要重复完成同一行为。

### 精进效果

精进效果由具体法术决定，不同等级可以改变数值，也可以解锁新的机制：

- **初识**：法术的基础效果；
- **熟练**：小幅改善伤害、范围、持续时间、冷却或魔力消耗；
- **掌握**：完善法术的主要功能，使其适合稳定使用；
- **共鸣**：强化法术与流派属性、状态效果或其他法术的联动；
- **谐律**：解锁法术的特殊效果、施法变化或新的战斗用途。

精进不应只表现为基础伤害增加。一个法术的高等级效果可以改变范围、目标数量、状态触发方式、持续时间或施法行为，使玩家能够感受到法术本身逐步完整。

例如，火球术可以拥有以下精进方向：

```text
初识：发射火球并造成基础伤害
熟练：提高伤害或飞行速度
掌握：扩大爆炸范围
共鸣：燃烧目标受到火球伤害时触发额外效果
谐律：命中后产生二次爆炸，或稳定附加灼烧
```

### 材料与条件

精进材料由数据包配置，每个阶段可以使用不同的材料组合。材料通常由三类组成：

- **通用源质**：作为法术精进的基础成本；
- **流派材料**：体现炽焰、寒冰、风暴、磐石和神圣等流派；
- **法术专属材料**：体现具体法术的主题，通常用于高等级精进。

精进条件与材料成本分别计算。材料表示完成精进所需的工艺资源，Condition 表示法术知识、战斗经历或世界进度上的门槛。

普通法术的前期精进通常不设置强制 Condition。例如火球术从初识提升至熟练、掌握时，玩家满足材料要求即可完成升级。高等级或高强度法术可以要求一次性的战斗、探索、任务或知识条件，例如：

- 完成指定的流派试炼；
- 击败与法术主题相关的敌人；
- 获得指定法术、符文或研究记录；
- 在特定地点完成一次施法行为；
- 先将另一法术提升至指定等级。

条件必须在界面中明确显示，不能通过隐藏计数或重复刷取来完成。

### 精进界面

在法术详情界面进入法术精进页面后，显示以下内容：

- 当前精进等级和法术效果；
- 下一等级的效果变化；
- 当前阶段所需的材料及持有情况；
- Condition 的具体描述和完成状态；
- 精进按钮。

当材料和必要条件均满足时，玩家可以确认精进。精进完成后，法术等级立即提升，材料被消耗，并更新法术的效果描述。

### 设计原则

法术精进应当让玩家获得新的战斗选择，而不是要求玩家为每个法术重复刷取使用次数。默认情况下，材料足够即可进行普通法术的精进；Condition 只在能够表达法术主题、世界进度或高强度效果的情况下使用。
