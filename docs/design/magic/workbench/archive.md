# 档案台

档案台（Archive）是用于查阅法术详情、编辑法术组和精进法术的功能方块。

## 基本结构

打开档案台后，界面采用翻开的书本或档案袋的布局。

- **图鉴页**显示法术列表，选择法术后在右侧展示详情。详情提供精进入口。
- **法术组页**可以编辑已保存的法术组，也可切换当前用于施法的法术组，沿用[随身法术界面](../gui/spell-ui.md#法术组编辑)的规则。

### 精进界面

从已解锁法术的详情进入精进界面。每次精进提升一级。材料、进阶条件与效果规则见[法术精进](../mechanics/mastery.md)。

界面显示当前精进等级、下一等级的效果变化、所需材料及玩家持有量。下一阶段有 `Condition` 时，显示条件描述、完成状态及其对本次精进的影响。强制条件未完成或材料不足时，界面提示原因。达到最高等级时，界面显示当前效果。

玩家确认精进后，消耗所需材料，立即更新等级、法术描述和下一阶段的预览。
