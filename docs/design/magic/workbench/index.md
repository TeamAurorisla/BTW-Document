# 功能方块

「Arcane Renaissance · 奥法新生」共新增了 **9** 和功能能方块，分别是：

## 基础工作台
- **研钵** Mortar：最简单的手工材料方块，用于研磨和改变材料形态。
- **窑炉** Kiln：贯穿全流程的，用于冶炼、熔炼粗矿和融合不同材料。
- **蒸馏器** Alembic：用于蒸馏，提纯盐与精华，或是合成新的材料

## 进阶工作台
- **铭刻仪** Inscriber：通过铭刻，赋予材料新的特性。也可以用来合成符卡或符文。
- **凝练仪** Concentrator：用于聚焦、纯化的材料的已有属性，凝练成高级材料。
- **蕴仪** Imbuer：通过蕴仪，可以让材料充盈、活化或精华化

## 法术与法杖工作台

- 抄写台（暂命名）：用于查看，升级法术
- 合成台（未命名）：大型多方块结构，用以合成法术卷轴或其他重要成品
- 工匠台（未命名）：合成/升级法杖
