# 功能方块

「Arcane Renaissance · 奥法新生」共新增了 **9** 和功能能方块，分别是：

## 基础工作台
- **研钵** Mortar：用于研磨，改变材料的形态
- **窑炉** Kiln：用于冶炼，融合不同的材料或熔炼粗矿
- **蒸馏器** Alembic：用于蒸馏，提纯盐与精华，或是合成新的材料

## 进阶工作台
- 铭刻（未命名）：通过铭刻，赋予材料新的特性。也可以用来合成符卡或符文。
- 聚焦（未命名）：极化材料的性质，改变物质形态
- 祝福/调谐（未命名）：通过祝福或调谐，建立魔法与材料的关系

## 法术与法杖工作台

- 抄写台（暂命名）：用于查看，升级法术
- 合成台（未命名）：大型多方块结构，用以合成法术卷轴或其他重要成品
- 工匠台（未命名）：合成/升级法杖
