# 法杖装配台

法杖装配台（Staff Assembler）用于组装、强化和拆解法杖。

## 基本结构

玩家放入物品后，装配台按物品切换界面。

| 放入的物品 | 界面与操作 |
| --- | --- |
| 可作为法杖核心的材料 | 进入装配界面。该材料用作核心，玩家补齐杖身、杖芯和绑定结后可预览并组装法杖。 |
| 成品法杖 | 进入强化界面，可镶嵌符文。 |
| 受损法杖 | 进入拆解界面，可回收部分材料。 |

其他物品不会触发模式切换。部件资格、属性计算和强化规则见[法杖设计](../staff/index.md)。

## 美术

不用很复杂，类似[美化 · 植物学家工作台](https://www.mcmod.cn/item/967008.html)的设计就可以了。不需要动画。
