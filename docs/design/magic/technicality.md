# 配置与技术约定

## 配置

初始解锁名单和玩法数值支持通过配置文件调整。初始解锁名单以法术 ID 指定。机制页中的魔力容量、恢复速率、超载和积势参数，以及法杖等系统的平衡数值，作为默认值或原型测试值记录在各自章节。

具体法术的精进材料、工坊配方等内容继续由对应的数据包定义。基础机制实现后，再根据实际生成的配置补充独立参数表，记录键名、默认值、取值范围和生效时机。

## 统计数据

- 模组会新增关于法术使用数量、法术精进的统计数据，方便之后的数据分析

## 自定义事件与数据定义

魔力 API、自定义事件和数据序列化约定，待相应机制实现后补充。
