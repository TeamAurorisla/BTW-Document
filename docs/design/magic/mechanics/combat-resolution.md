# 施法与伤害结算

::: warning 结算草案
本页记录奥法新生的施法流程和伤害公式，供战斗原型验证。魔力费用的试算、扣除与返还见[魔力](../mana/index.md)。延迟效果的属性读取时机仍待确定。
:::

## 法杖施法

1. 玩家选择候选法术，满足[吟唱规则](./mechanics.md#法术吟唱)后尝试施放。
2. 检查法杖、候选法术和目标，并按法术的释放类型判断是否需要回退到另一种目标方式。再读取当前精进等级和装备修正，计算[实际费用](../mana/index.md#施法费用)，检查魔力和[超载条件](../mana/mana-overload.md#触发条件)。史诗法术还需满足[积势门槛](./momentum.md#史诗法术)。
3. 施法成立时结算魔力、法杖耐久和积势，并补充候选槽。史诗法术以清空前的积势计算本次效果。
4. 伤害与状态效果按法术的命中或生效条件结算。投射物未命中时，已成立的施法照常消耗资源。

取消选择或未通过施法检查时，资源与候选槽保持原状。法术的命中返还效果按具体条目和[魔力返还规则](../mana/index.md#支付与返还)处理。

## 百分比修正

所有百分比修正以 0 为中性值，计算时用小数表示，例如 +20% 写作 $0.2$。每个乘算组用 $1+\text{修正}$ 换算为倍率，乘算组最低为 0。

## 法术伤害

$$
D_{\text{spell}} = B_{\text{spell}}
\times \max(0, 1 + A + M)
\times \max(0, 1 + S k)
\times \max(0, 1 + P + O)
$$

| 符号 | 含义 |
| --- | --- |
| $B_{\text{spell}}$ | 当前精进等级下，该次伤害效果的基础值。 |
| $A$ | 与该法术流派对应的流派亲和修正。 |
| $M$ | 魔力修正，例如状态效果提供的通用伤害增减。 |
| $S$、$k$ | 施法者的法术强度修正，以及法术条目中的「法术强度倍率」，即该修正对本法术的作用系数。 |
| $P$ | 史诗法术由积势换算出的伤害修正。其他稀有度取 0。 |
| $O$ | 当前伤害效果的其他独立修正。已经计入 $A$、$M$ 或 $S$ 的效果只结算一次。 |

例如，初识火球术基础伤害为 16、法术强度系数为 0.5。所有修正为 0 时伤害为 16。若只有法术强度 +20%，伤害为 $16\times(1+0.2\times0.5)=17.6$，再交给受击结算。

## 魔弹伤害

$$
D_{\text{missile}} = B_{\text{missile}}
\times \max(0, 1 + A + M)
\times \max(0, 1 + S k_{\text{missile}})
$$

$B_{\text{missile}}$ 为法杖的面板魔弹伤害，$k_{\text{missile}}$ 的当前试算值为 0.2。普通魔弹的 $A$ 为 0。魔弹经流派符文转化后，$A$ 取对应流派的亲和修正。

## 法术抗性

对适用法术抗性的伤害，通用抗性与对应流派抗性分别乘算。

$$
D_{\text{resisted}} = D \times (1 - R_{\text{general}}) \times (1 - R_{\text{school}})
$$

$D$ 为进入法术抗性结算的伤害。两类抗性的取值范围均为 $[-1,1]$，其中 $-1$ 对应该项造成双倍伤害，$1$ 对应该项免疫。无对应流派抗性时，该项取 0。伤害是否计入护甲见[伤害类型](./damage-types.md)，护甲等减伤与抗性的具体先后顺序待原型确认。
