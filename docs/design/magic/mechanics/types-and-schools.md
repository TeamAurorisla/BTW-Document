# 法术类型与流派

## 法术类型
根据功能划分，有攻击、防御、增益、召唤四个类型。  
- 确保每个法术流派均有这四类法术。
根据稀有度划分，有普通，稀有，史诗三个类型（仅指法术槽中的法术）。  
- 可主动解锁的法术只有普通、稀有和史诗，每个法术流派最多有 2 个史诗法术。
- 法术的稀有度在一定程度上与法术的费用有关。一般而言，法术越稀有，费用越高，但允许特殊情况。需要注意的是，大型法术（需要魔力 18 以上）不可能是普通法术。

::: tip 关于「传奇法术」
设计中还存在一种名为「传奇法术」的特殊内容。**传奇法术并不属于法术体系**，而是归属于能力技能，不占用任何法术槽，无法进行法术精进，也不受流派属性影响。详见 [能力技能 - 传奇法术](../../abilities/legendary-spells/index.md)。
:::
根据魔力消耗划分，有小型法术（1-8），中型法术（8-18）和大型法术（18+）。  
- 魔力槽的上限为20，但是法杖可以优化魔导效率，因此实际法术消耗可以大于20。
- 除了魔力外，大型法术的释放还受到积势的影响：当积势较高时，法术的威力和效果会得到提升，当积势较低时，法术的威力和效果会受到削弱。大型法术的释放会清空积势。玩家释放法术会积累积势。

## 法术流派
法术被划分为了多个不同的流派。每个流派有各自特别的特性和视觉效果。正常情况下，玩家在通关时可以解锁2-3个法术流派的全部法术和其他流派的大部分法术。  
目前有如下 5 个流派：炽焰、寒冰、风暴、磐石、神圣。我们会优先完成前四个元素流派，之后也有可能设计更多流派。

每个流派应当包含完整的法术系统，并在设计上有所侧重与独特的优势：

- 炽焰：扩散范围伤害（由内向外逐渐降低），持续伤害；在防御和增援上倾向反击
- 寒冰：单体伤害，持续敌人减益；在防御上倾向保持安全距离
- 风暴：单体伤害，高命中率；在防御上倾向于隔离（击退，眩晕）
- 磐石：均匀群体伤害，伤害高，节奏慢，成本高；在防御上倾向死守
- 神圣：重视名正言顺，更复杂的步骤换更高的伤害；在防御上倾向于治疗

## 流派属性

流派属性是多个法术共有的属性与能力，一般侧重于多个法术的组合和积累。正常情况下，流派属性会和流派挂钩，但是也允许特殊的流派属性。

流派属性对于法术而言应该有一个明确的接口与能力规模，以适配通用的能力。
