# 法术精进

法术精进是提升法术威力和效果的过程。通过法术精进，玩家可以提升法术的基础伤害、附加效果等属性，也可以解锁新的施法机制。法术精进包括五个等级：**初识 → 熟练 → 掌握 → 共鸣 → 谐律**。

玩家解锁法术时，法术处于**初识**等级。每次精进只能提升一级，升级必定成功，并消耗该阶段要求的材料。精进不消耗玩家经验，材料需求由数据包配置。

## 精进效果

精进效果由具体法术决定，不同等级可以改变数值，也可以解锁新的机制：

- **初识**：法术的基础效果；
- **熟练**：小幅改善伤害、范围、持续时间、冷却或魔力消耗；
- **掌握**：完善法术的主要功能，使其适合稳定使用；
- **共鸣**：强化法术与流派属性、状态效果或其他法术的联动；
- **谐律**：解锁法术的特殊效果、施法变化或新的战斗用途。

精进不局限于基础伤害提升。具体法术可以通过精进改变范围、目标数量、状态触发方式、持续时间和施法行为。

## Condition

每个精进阶段可以单独配置一个 `Condition`。Condition 是该阶段的附加条件，可以为空，也可以是可选条件或强制条件：

- **无条件**：满足材料要求后即可精进，适用于大多数普通法术；
- **可选条件**：满足后获得额外效果、降低材料消耗或解锁额外分支，不影响基础精进；
- **强制条件**：必须满足后才能精进，适用于高强度法术或具有特殊剧情、战斗意义的效果。

Condition 是一次性门槛，不是可重复刷取的经验系统。条件完成后永久记录，玩家不需要重复完成同一行为。

Condition 可以由数据包配置为：

- 完成指定的流派试炼；
- 击败与法术主题相关的敌人；
- 获得指定法术、符文或研究记录；
- 在特定地点完成一次施法行为；
- 先将另一法术提升至指定等级。

普通法术的前期精进通常不设置强制 Condition。高等级或高强度法术可以使用一次性的战斗、探索、任务或知识条件作为门槛。

## 精进材料

精进材料由数据包配置，通常由三类材料组成：

- **通用源质**：作为法术精进的基础成本；
- **流派材料**：体现炽焰、寒冰、风暴、磐石和神圣等流派；
- **法术专属材料**：体现具体法术的主题，通常用于高等级精进。

精进材料与 Condition 分别计算。材料表示完成精进所需的工艺资源，Condition 表示法术知识、战斗经历或世界进度上的门槛。

## 设计原则

法术精进默认由材料完成，Condition 只在能够表达法术主题、世界进度或高强度效果的情况下使用。系统不要求玩家为每个法术重复刷取使用次数，也不设置统一的法术经验条。
