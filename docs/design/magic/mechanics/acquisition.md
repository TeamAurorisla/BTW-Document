# 法术的获得

法术可以通过研究、探索、战斗、任务和法术精进等途径获得。不同法术可以拥有不同的获取方式。

## 研究解锁

正式的法术研究通过[编纂仪（Codifier）](../../magic/workbench/codifier.md)进行。编纂仪是合成法术卷轴的唯一设备，也是进入正式法术研究的准入门槛。

玩家将法术配方要求的核心材料、普通材料、特殊材料和奥术书页放入编纂仪，关闭核心槽的观察窗后，机器会检查配方并执行编纂。配方合法时，编纂仪消耗奥术书页，产出对应的法术卷轴。

一份法术配方最多包含：

```text
1 个核心材料 + 4 个普通材料 + 2 个特殊材料
```

核心材料放入核心槽；普通材料放入四个普通试剂槽；特殊材料放入靠近中央的两个特殊试剂槽。普通试剂槽和两个特殊试剂槽各自采用无序匹配，材料种类和数量必须与配方要求完全一致。

获得法术卷轴后，使用卷轴即可解锁对应法术。相同配方可以重复产出法术卷轴。

## 探索与战斗

部分法术卷轴可以通过探索世界、击败敌人或发现特殊结构直接获得。此类法术不要求玩家先通过编纂仪研究，使用卷轴即可解锁法术。

## 任务解锁

部分法术通过完成任务、成就或剧情事件解锁。具体法术可以直接解锁，也可以将法术卷轴作为任务奖励。

## 精进解锁

部分法术会在其他法术达到指定精进等级后解锁。达到条件后，玩家可以直接获得法术，也可以获得对应的编纂配方或法术卷轴。

## 配方查看

法术配方可以通过 JEI 查看；已经接入法术界面的配方，也可以在法术 GUI 中使用 R 键查看。
