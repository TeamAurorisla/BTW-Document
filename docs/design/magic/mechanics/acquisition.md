# 法术的获得

法术可以通过初始解锁、研究、探索、战斗、任务和法术精进等途径获得。不同法术可以拥有不同的获取方式。

## 初始解锁

玩家的初始法术名单由[配置](../technicality.md#配置)指定。名单可以少于 8 个，玩家可按[法术组规则](./mechanics.md#法术组)将它们全部编入法术组。完整的默认名单随各流派的内容设计确定。

## 研究解锁

正式的法术研究通过[编纂仪（Codifier）](../workbench/codifier.md)进行。编纂仪是合成法术卷轴的唯一设备，也是进入正式法术研究的准入门槛。

玩家按配方放入核心材料、试剂和[[arcane_materials:ink_crystal_page]]，关闭观察窗启动编纂。编纂成功时消耗书页并产出对应的法术卷轴。投料位置和配方匹配方式见[编纂仪的配方规则](../workbench/codifier.md#配方与编纂)。

获得法术卷轴后，使用卷轴即可解锁对应法术。相同配方可以重复产出法术卷轴。

## 探索与战斗

部分法术卷轴可以通过探索世界、击败敌人或发现特殊结构直接获得。此类法术不要求玩家先通过编纂仪研究，使用卷轴即可解锁法术。

## 任务解锁

部分法术通过完成任务、成就或剧情事件解锁。具体法术可以直接解锁，也可以将法术卷轴作为任务奖励。

## 精进解锁

部分法术会在其他法术达到指定精进等级后解锁。达到条件后，玩家可以直接获得法术，也可以获得对应的编纂配方或法术卷轴。

## 配方查看

法术配方可以通过 JEI 查看；已经接入法术界面的配方，也可以在法术 GUI 中使用 R 键查看。
