# 战斗系统

## 数值运算方式（草稿）

### 法术伤害

$$
D_{\text{spell}} = (B + M_{\text{flat}}) \times (1 + A + C_{\text{mana}}) \times (1 + P \times k_P) \times (1 + G + S + O)
$$

| 符号 | 名称 | 说明 |
|------|------|------|
| $B$ | 基础法术伤害 | 由法术稀有度决定 |
| $M_{\text{flat}}$ | 法术精进伤害 | 精进等级提供的固定加成 |
| $A$ | 流派亲和 | 法杖部件提供，范围 $0 \sim 0.5$ |
| $C_{\text{mana}}$ | 魔力修正 | 来自魔力超载/环境效果，范围 $-0.2 \sim +0.2$ |
| $P$ | 法术强度 | 法杖部件提供，范围 $0 \sim 100$ |
| $k_P$ | 法术强度倍率 | 固定值 $0.012$ |
| $G$ | 积势 | 范围 $0 \sim 0.5$，释放大型法术时清空 |
| $S$ | 状态效果 | 来自狂热、审判等，范围 $0 \sim 0.3$ |
| $O$ | 其他加成 | 来自顿悟构筑、环境共鸣等，范围 $0 \sim 0.2$ |

### 法术受击

$$
D_{\text{taken}} = D_{\text{spell}} \times (1 - R_{\text{general}}) \times (1 - R_{\text{school}})
$$

| 符号 | 名称 | 说明 |
|------|------|------|
| $R_{\text{general}}$ | 通用法术抗性 | 范围 $[-1, 1]$，$-1$ 为双倍伤害，$1$ 为免疫 |
| $R_{\text{school}}$ | 流派抗性 | 针对单一流派，范围 $[-1, 1]$ |
