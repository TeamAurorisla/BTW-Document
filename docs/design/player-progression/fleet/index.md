# 舰队

舰队是位于独立维度中的原创基地模组，承担仓储、建设、传送等后勤功能。舰队并非玩家成长的主要玩法，而是辅助玩家发展的配套设施，在功能定位上类似于《十字军之王 3》中的庄园。

玩家在任意世界中长按 `H` 即可进入舰队世界。

::: info 未来规划
目前舰队仅承担基地功能，未来可能会扩展更多玩法（如舰队日志、位置映射等），但其作为辅助机制的设计理念不会改变。
:::

## 舰船

舰队由两类舰船组成：**核心舰**与**支援舰**。核心舰是玩家的主要活动区域，支援舰则提供各类辅助功能。

### 核心舰

核心舰是玩家的主基地。玩家开局即拥有**旗舰**（一艘核心舰），其默认提供仓储、管理室、NPC 交互等基础功能，并预留了大量空舱室供玩家自由建设。

核心舰拥有舷号，玩家可以自定义舰船名称与舷号。

后续玩家还可以花费材料和经济资源购买**其他核心舰**。每艘核心舰都提供基础功能，但不同核心舰在侧重点上会有所差异。

### 支援舰

与可自由建造的核心舰不同，**支援舰的功能是固定的**：它们拥有实际的结构，但玩家无法在其中自行建设，仅能体验其提供的辅助功能。支援舰是玩家最主要的购买对象。

常见的支援舰包括：

- **仓储船**：提供额外的仓储空间
- **补给船**：提供食物与基础建材
- **商船**：在舰队上提供贸易功能

支援舰支持升级。升级**仅强化功能**而不改变舰船结构外观，例如：
- 仓储船升级后会额外提供 300 个仓储格子
- 商船升级后有更高概率出售高级材料

## 预览

在舰队维度中，玩家除了第一人称外，还可以切换至俯瞰视角，从全局查看整支舰队的布局，直观见证舰队的发展与壮大。每新增一艘舰船，舰队都会真实出现在世界中。
