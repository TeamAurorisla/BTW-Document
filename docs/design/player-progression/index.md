# 玩家成长


在航迹中，玩家成长主要由三个部分组成，即法术与能力、构筑、装备与饰品。其中，法术与能力和构筑是玩家的主要成长方式，而装备与饰品主要以数值提升为主。

``` mermaid
pie showData
    title 玩家成长组成
    "法术与能力": 40
    "构筑": 30
    "装备与饰品": 30
```

需要注意的是，法术系统对于玩家成长的影响主要体现在战斗能力上，而构筑系统则主要体现在整体能力上。

我们不设置专门的提升血量的手段，玩家的血量提升可以通过构筑系统，装备以及少部分不可合成的战利品道具实现。

## 难度曲线

航迹仅对难度进行小幅度的动态修改，主要体现在普通敌人的装备等方面。我们希望严格控制玩家的成长曲线上限，在游戏后期，玩家的生命上限不应该超过游戏初期的 10 倍，常规伤害上限不应超过游戏初期的 50 倍，伤害上限不应超过游戏初期的 100 倍。
