# 顿悟

航迹使用「顿悟 Epiphany」模组提供的模块化技能树作为构筑系统的核心组成部分。虽然顿悟其实是航迹的第一方模组，但考虑到模组的普适性，顿悟的文档独立于航迹之外，以便其他开发者也能使用。

- **选择模块**：技能树由许多独立的模块组成，玩家可以自由选择模块组合，形成独特的成长路线
- **点亮心得**：消耗资源点亮模块中的节点，实现数值与能力的逐步积累
- **决定顿悟**：当模块中的心得全部点亮，玩家将有机会抉择新的顿悟，带来机制性突破

目前虽然底层实现已经确定，但具体的玩法和内容仍在初步设计阶段，目前可以确定的是，航迹的顿悟模块更加会是综合性的内容，每一个模块中都会包括不同方向的心得。但一个模块本身的奖励会有所倾向。例如：
- 模块：骑士
    - 心得：战袍与纹章 - 伤害增加 2，血量上限增加 2，当玩家穿着套装护甲时，额外获得 速度/力量 增益效果。
    - 心得：虔诚信徒 - 使用神圣流派法术伤害增加 50%，血量上限增加 2。
    - 心得：骑士精神 - 与商人交易基础物品时打折 30%，最高血量上限增加 5 
    - 心得：领袖气魄 - 伤害增加 10%，增益法术与范围法术的法术强度增加 20%，血量上限增加 3
    - 心得：战士荣耀 - 伤害增加 2，护甲增加 2，经验获取增加20%

这一段并非正式的设计文档，只是目前的简单思路，以供参考。
