# 启示

::: info 计划内容
当前内容并没有设计于初始版本前制作完成，属于未来计划内容。
:::

「启示 Revelation」引入了一种特殊战利品——"神秘石板"。玩家可在释义台（Exegesis Table）上通过小游戏对其进行解密，成功后获得随机奖励与叙事文本。部分奖励具有唯一性，每位玩家仅能获取一次。神秘石板的奖励设有等级区分，类似钓鱼机制：玩家总能有所收获，但丰厚奖励全凭运气。

神秘石板对玩家发展路线有一定引导作用，并在功能上部分替代传统饰品，但整体影响控制在较小范围，定位为玩家成长的补充手段。奖励以通用性为导向，主要包括以下类别：
- 血量上限、心得点（顿悟）
- 原材料、法术卷轴
- 游戏剧情叙事
