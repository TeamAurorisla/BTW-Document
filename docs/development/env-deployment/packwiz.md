# 自动更新

鉴于团队内人员不少且像模组这类内容不方便更新，故我们使用 Packwiz 的自动更新机制，方便所有成员都可以在下次启动游戏时获取更新。

原理可以看 `BTW-Packwiz` 仓库的 [README](https://github.com/TeamAurorisla/BTW-Packwiz#btw-packwiz)，这里只介绍本地部署与管理的操作。

如果你需要更新模组，再看也无妨，这个页面不是所有成员必看的。

## 本地部署与管理

这个仓库可以克隆到你本地的随意位置，没有硬性要求。

> 推荐使用 Prism 启动器下载模组等内容。

1. 先克隆此仓库到本地。
2. 在本地下载或更新模组等内容后，手动将元数据文件复制至此仓库对应文件夹内，推送更改即可。

注意 `.pw.toml` 元数据文件不要改名，尤其不能改为中文名，Packwiz 是没办法正常识别的。

有些元数据文件也可能无法被 Packwiz 正常识别，这时一般需要手动填写一下 `side` 属性（填个 `both` 就行）。
