# 环境部署

## 了解仓库结构

与整合包相关的一共有3个仓库，分别为：

- [Beyond-The-Wake](https://github.com/TeamAurorisla/Beyond-The-Wake)
- [BTW-Packwiz](https://github.com/TeamAurorisla/BTW-Packwiz)
- [BTW-Document](https://github.com/TeamAurorisla/BTW-Document)

第一个为整合包文件储存库，即主仓库；

第二个为更新模组等需下载内容的仓库；

第三个为本文档仓库。
