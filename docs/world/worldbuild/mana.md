# 魔力

> 魔力的美妙之处不在于其神秘莫测，而在于能够受到人类的理解与掌握。熟知它的规律与特性，便可创造奇迹。
> <div style="text-align: right;">——《标准魔法论》</div>

魔力来自于本源，是一种特殊的能量，可以被感知、使用、储存、传输。人类无法直接运用魔力，而是需要流派或魔导器作为中介，将魔力塑性为可以被掌握并使用的形式。通过学习，魔法使们可以掌握魔法的技艺，并通过不同流派释放法术。

魔法的基本过程是：

```text
本源 → 魔力 → 流派 → 法术
```

## 本源

**本源**是一切魔法可能性的起点，其没有界限，亦无法被定义，是失落文明魔法使们毕生追求着的终极目标。魔力来自本源，但本源并不是更高等级的魔力，也不是可以直接储存和使用的能源。

人类不能直接理解本源，只能观察它进入现实后留下的魔力与现象。本源本身无法被直接观测。它进入有限的现实并受到世界规律约束后，才显现为可以被感知和利用的魔力。

故事发生时代的人们能够认识和利用魔力，但尚不知道本源的存在，也不知道魔力的真正来源。航迹仅在形而上学上会谈及本源，在游戏中玩家不会接触或使用本源。


## 魔力

**魔力**是本源在现实中的显现，是一切魔法现象的基础。魔力没有属性，也没有固定的效果；未经中介塑形的魔力无法成为具体法术。

根据魔力与生命个体的关系，可以将其分为内源魔力与外源魔力。二者是同一种魔力，而非两种不同的能量。

- **内源魔力**：被生命吸收并与个体稳定结合的魔力。它属于个体，能够逐渐恢复，但容量受到个体自身限制。游戏中表现为**稳态魔力**。
- **外源魔力**：尚未与个体稳定结合、广泛存在于环境和其他事物中的魔力。战斗会使其产生流动，施法者可以暂时捕获并使用它。游戏中表现为**涌态魔力**。

## 流派

**流派是连接魔力与法术的中介工具**，而不是对既有法术的分类或总结。

无定形的魔力必须经过流派的约束，才能获得可以被人类理解和控制的形式。不同流派以不同方式筛选、引导和塑造魔力，由此决定魔力能够形成何种法术。

炽焰、寒冰、风暴、磐石与神圣并不是五种天然存在的魔力，而是五种经过验证的利用魔力的中介。流派使施法变得稳定、可学习和可重复，同时也排除了不符合其结构的其他可能。

## 法术

**法术**是魔力经过流派塑形后形成的、可以稳定复现的魔法现象。术式规定具体的塑形过程，法杖则协助施法者引导魔力并执行术式。

因此，魔法并不是直接支配本源，而是借助流派这一中介，将魔力转化为有限而确定的结果。

## 魔力超载

当可用魔力不足时，施法者可以强行调用原本用于维持自身魔力平衡的内源魔力完成施法，这就是**魔力超载**。超载会暂时降低稳态魔力上限，直到个体重新恢复稳定。

失落文明所追寻的，则是绕过或突破这些中介与边界，触及流派无法实现的可能。

### 前夜

一般认为，现代魔法学科的起源可以追溯到文艺复兴时期，并经历了漫长的发展过程。在早期历史中，魔法主要存在于宗教仪式、宫廷秘术以及民间传统之中。人类已经能够使用魔法，但对于魔法产生的原因与运行规律缺乏系统认识，多数施法者依赖传统仪式与宗教遗物施展魔法。由于缺乏理论体系，早期魔法具有高度地域性和神秘性，魔法现象多被解释为神迹、自然力量或祖先祝福。

文艺复兴时期，人文主义学者们开始重新研究古代文明留下的神秘学文献。通过比较不同地区的仪式记录，学者逐渐发现，魔法并非完全依赖施法者意志，而存在可以重复观察的结构。在这一基础上，诞生了早期法阵学，首次区分出了魔法结构中的必要条件与不同魔法之间的共同规律。

十六世纪，《神秘学》出版，该书通常被认为是第一部尝试系统解释魔法原理的著作。尽管其理论存在大量的错误，但其首次提出，魔法可以作为一种知识体系被研究。《神秘学》标志着魔法从宗教仪式走向世俗，初步形成了世俗魔法体系，即如今的通用魔法（Common Magic）。该书推动了早期魔法教育的发展，并成为后来魔法学理论的重要研究对象。

### 黎明

十七世纪之后，随着实验方法的发展，魔法研究进入系统化阶段。《常识》与《标准魔法论》的出版，被认为标志着现代魔法学的形成。《标准魔法论》建立了元素分类体系与魔力测量方法，意味着魔法成为了有逻辑成体系的学科，标准化、系统化的元素魔法理论正式确立。

然而，魔法世俗化引发传统宗教体系的强烈反应。部分教廷人士认为：魔法属于神圣领域，教会享有魔法的专有权，学者无权独立研究。然而，也有部分神学家支持魔法研究，认为探索魔法规律即是在理解世界秩序。这一争论持续数百年，并最终推动了宗教改革与现代魔法教育制度的发展。

### 第一次魔法革命

第一次魔法革命也被称为启蒙革命。殖民扩张与远洋贸易迫切需求能改变自然环境的实用技术。随着理论魔法的发展，魔法开始进入社会生产领域，并在航海、农业、医疗等方面发挥了重要作用。与此同时，由于魔法研究需要大量资源，魔法逐渐与新兴商业阶层产生联系。魔法工房成为早期魔法产业的重要形式。

### 第二次魔法革命

第二次魔法革命也被称为工业革命。十八世纪，魔力储存技术取得突破，使得魔法开始摆脱对个人施法者的依赖。在这一时期，出现了大型魔导装置与可被大众使用的魔导具。在这一阶段，传统魔法学开始分化为不同的学科，逐渐形成现代学科体系

### 第三次魔法革命

第三次魔法革命也被称为工程革命。二十世纪以来，由于战争和工业需求，魔法系统开始追求进一步的简化与自动化。机械工程与魔法理论进一步结合，形成了远超过去魔法工房所能承接的复杂系统与需求。在这一过程中，出现了工房魔法和工业魔法的分流。工房魔法强调精密设计，主要应用于学术研究；工业魔法强调自动化与批量生产，应用于大规模社会生产。现代魔法体系正式形成。

如今，魔法学也在不断的发展中，推动社会的发展与变革。
