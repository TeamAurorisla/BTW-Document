# 世界观

::: tip
草稿，不具有最终权威性，后续可能会有较大改动。
:::

「航迹」的世界以 16 至 17 世纪欧洲地理大发现时代为主要原型，处于近代的黎明。魔法并非少数人偶然获得的神秘力量，而是一种已经开始被观察、研究和传授的技艺。随着实验方法与标准魔法理论出现，依赖宗教仪式、地方传统和个人经验的古老魔法，正逐渐转变为系统化的近代魔法。

## 魔法

世界中的一切魔法都以魔力为基础。魔力本身没有属性和固定效果，人类借助流派或魔导器作为中介，对魔力进行引导和塑形。

```text
本源 → 魔力 → 流派 → 法术
```

故事发生时代的人们已经能够感知、测量和利用魔力，却尚不知道本源的存在，也不知道魔力真正来自何处。流派是一种经过验证的利用魔力的管道而非魔力的分类。

魔法的系统化改变了社会，魔法使逐渐形成新的专业阶层。虽然魔法仍远未成为人人都能使用的日常技术，但它已经开始参与国家秩序与时代变革。

## 王国与地理大发现时代

在复兴运动与近代魔法发展的推动下，王国完成统一，并建立起强大的中央集权政权。掌握系统魔法知识的高阶魔法使凭借专业能力获得财富、地位与政治影响力，这些依附于王权的新兴贵族，被称为“持杖贵族”。

与此同时，航海技术与实用魔法的发展使远洋探索成为可能。王国将野心投向旧大陆之外：人们渴望寻找财富与土地，追求知识与荣誉，亦或只是希望踏入尚未被地图记录的世界。

## 黎明群岛

黎明群岛（Aurorisla）是远离旧大陆的海岛世界，也是「航迹」故事发生的主要舞台。王国在此设立总督区，并以黎明城作为开发群岛的据点。然而，殖民者对群岛的认识仍十分有限：海盗与敌对势力争夺航路，魔物盘踞于荒野，广阔海域中还散布着尚未得到记录的岛屿、聚落和遗迹。

丰富的银矿和黄金资源与失落文明遗迹吸引着探险者趋之若鹜。大多数人只在遗迹中看见宝藏、材料与古代魔法，真正试图理解失落文明为何繁荣、又为何消失的人少之又少。

## 失落文明

失落文明曾在群岛上建立繁荣的城市与远超现代认知的魔法体系。它是一个由不同城市、传统与思想构成的文明。其学者曾沿着不同道路研究魔力，逐渐触及流派与法术背后更深层的结构。

这些道路既留下了伟大的成果，也留下了至今仍在影响群岛的遗迹、魔物与异常现象。现代世界并不知道他们真正追寻的目标，也无法解释文明失落的原因。有关本源、学派和文明结局的真相，将随着玩家的探索逐步显现。

## 玩家

玩家是一名刚从学院毕业的年轻魔法使，也是落魄贵族的后裔。在朋友与资助者、黎明总督维伦·德·诺马尔赫的邀请下，玩家来到群岛成为探险家，希望寻找财富与名誉，也追寻魔法的智慧与奥秘。

玩家起初只是众多探险者中的一员。随着一次次远征，玩家与维伦将逐渐把散落于群岛各处的线索联系起来，成为少数真正接近失落文明真相的人。
