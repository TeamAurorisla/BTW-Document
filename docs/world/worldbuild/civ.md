# 世界观设定：失落文明

> 魔术是人类智慧所及之尽头的世界。  
> 魔法是不被那其中的任一所涵盖的，属天之外的孤独存在。  
> 开始，第一道改变了一切。  
> 之后，第二道认可了更多。  
> 接着，第三道预示了未来。  
> 随之，第四道隐藏了身影。  
> 然后，最后的第五道早已失去了意义。  
> <div style="text-align: right;">《魔法使之夜》</div>


群岛阻隔又联结着人们，破碎的岛屿上曾发展出繁荣的城市与彼此相异的传统。它们共同构成了如今所称的失落文明，并拥有远超当世认知的魔法。

失落文明中的魔法使发现，流派是人类塑造魔力、释放法术的中介。它使魔法稳定而可控，同时也限制了魔法能够实现的可能。沿着魔力追溯其来源，他们逐渐触及一切魔法可能性的起点——本源，并尝试越过流派与魔力的边界，以人的存在直接接近它。

## 学派与人的有限性

失落文明的学派由此诞生。这里的“学派”并非炽焰、寒冰等法术流派，而是围绕本源形成的思想与研究道路。它们尝试回答同一个问题：**人的有限性究竟是需要被克服的缺陷，还是人成其为人的必要条件？**

不同学派从五个逐渐扩大的层面尝试回答这个问题：

1. **避免死亡**：消除生命在时间中的终点，使人得以永远存在。
2. **摆脱肉体**：让意识脱离脆弱的物质载体，获得更加完整的存在形式。
3. **绝对理性**：排除情感、欲望与偏见，使人能够作出完全理性的判断。
4. **知晓未来**：克服认知与因果的不确定，洞悉选择所通向的一切结果。
5. **创造世界**：不再受既有现实限制，亲自从无限可能中创造一个世界。

这些学派并非因愚昧、疯狂或傲慢而受到惩罚。它们发现的问题真实存在，提出的答案伟大而合理，也确实取得了成功。其悲剧来自答案被完整实现之后产生的新问题：当一种限制被消除，由这种限制维系的事物也会随之改变。

因此，各学派不应重复“研究失控并导致毁灭”的同一种故事。它们可能毁灭、停滞、分裂、主动放弃，也可能从未真正失败。失落文明的衰亡是这些成功、代价与选择长期累积的结果，而非某个疯狂学派造成的单一灾难。

## 文明的封存

在文明最后的时代，不同学派的道路最终汇聚。即使拥有绝对理性、知晓未来乃至创造世界的能力，人仍然必须决定什么值得选择，并为没有被选择的可能负责。任何成为现实的世界都必然具有边界；没有边界的，只是尚未成为任何事物的可能性。

先民最终创造了一个与现世隔绝的世界，并将通向本源的知识与学派之间的联系封存其中。这个世界便是末地。封存不是因为他们否定了自身的探索，而是他们在理解其成果之后作出的最后选择。

此后的灾难、迁徙与漫长时间使文明彻底消逝，只留下彼此孤立的遗迹。失落文明既被历史遗忘，也曾主动使自己成为失落的文明。
